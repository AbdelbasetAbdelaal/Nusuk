# Nusuk Key Hunter

تطبيق أندرويد لتنظيم أكواد الدعوة:
- فتح روابط مجموعات ومنشورات فيسبوك التي أضافها المستخدم.
- استقبال نص منشور أو تعليق يشاركه المستخدم إلى التطبيق.
- استقبال النص المحدد من تعليق عبر خيار Nusuk Key Hunter في قائمة تحديد النص على أندرويد، إن أتاح تطبيق فيسبوك هذا الخيار.
- لصق عدة تعليقات في حقل مخصص واستخراج أكواد الدعوة بصيغة NG- وإزالة التكرار.
- نسخ الكود التالي لتجربته يدويًا في نسك ثم تسجيل النتيجة.
- حفظ القائمة والنتائج محليًا.

## فحص التعليقات
1. افتح المنشور في فيسبوك.
2. اضغط مطولًا على نص التعليق وحدده.
3. من قائمة تحديد النص اختر «المزيد» ثم Nusuk Key Hunter، إذا ظهر ضمن الخيارات.
4. أو انسخ نص تعليق/تعليقات والصقه في حقل «استخراج الأكواد من التعليقات».
5. اضغط «فحص التعليقات واستخراج الأكواد».

## حدود الوصول
التطبيق لا يفتح تعليقات المجموعات ويجمعها في الخلفية أو يتصفحها آليًا. أزالت Meta Groups API في 22 أبريل 2024، كما أن قراءة تعليقات المنشورات عبر Graph API تخضع لصلاحيات تعتمد على نوع المنشور والجهة المالكة وإذن التطبيق. لذلك يعتمد هذا الإصدار على النص الذي تختار نسخه أو مشاركته بنفسك، ولا يطلب كلمة مرور فيسبوك أو رمز تحقق ولا يتجاوز قيود المنصة.
