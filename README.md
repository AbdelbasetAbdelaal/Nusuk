# Nusuk Key Hunter

تطبيق لتنظيم أكواد الدعوة التي تبدأ بـ NG-:
- فتح روابط المجموعات والمنشورات التي يضيفها المستخدم.
- استقبال نص مشترك أو نص محدد من فيسبوك.
- فحص النص المنسوخ في الحافظة مع عرضه في حقل التعليقات قبل الفحص.
- التعرّف على NG- مع اختلاف أنواع الشرطات والمسافات ومحارف Unicode المخفية.
- منع التكرار ونسخ الكود التالي وتسجيل النتيجة.

مهم: التطبيق يفحص النص الذي يتم نسخه أو مشاركته معه فقط. لا يقرأ تعليقات مجموعات فيسبوك تلقائيًا من الخلفية، لأن ذلك يتطلب صلاحيات وصول رسمية متاحة لهذا النوع من المحتوى.

## الاستخدام
1. افتح التعليق في فيسبوك وانسخ النص الذي يحتوي على الكود كاملًا.
2. ارجع إلى التطبيق واضغط «فحص النص المنسوخ في الحافظة عن أكواد NG».
3. سيظهر النص المنسوخ داخل مربع التعليقات، وستظهر نتيجة الفحص.
4. يمكن أيضًا لصق النص في المربع والضغط على «فحص التعليقات واستخراج الأكواد».
