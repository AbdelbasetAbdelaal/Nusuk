# Nusuk Key Hunter

منظّم أكواد الدعوة ومساعد إدخال يدوي داخل تطبيق نسك.

## مساعد نسك
1. اضغط «نسخ الكود التالي وفتح تطبيق نسك».
2. يختار التطبيق أول كود معلّق، ينسخه إلى الحافظة، ثم يفتح تطبيق نسك الرسمي.
3. أدخل الكود في خانة الدعوة داخل نسك بنفسك.
4. ارجع إلى Nusuk Key Hunter واضغط «تم قبوله» أو «مرفوض / مستخدم».
5. يعرض التطبيق نتيجة كل كود، ويحفظ الكود الحالي وحالات الأكواد محليًا، ثم اختر التالي.

المساعد لا يقرأ بيانات الدخول ولا يرسل الكود أو يفعّل الدعوة نيابةً عنك. لا يوجد تكامل رسمي معلن يتيح لتطبيق طرف ثالث تعبئة نموذج الدعوة في نسك تلقائيًا. صفحة Google Play الرسمية لتطبيق نسك: https://play.google.com/store/apps/details?id=com.moh.nusukapp

## إدارة الأكواد
- استخراج الأكواد التي تبدأ بـ NG- من النصوص المنسوخة أو المشاركة.
- إزالة الأكواد المكررة.
- عرض حالات الأكواد: معلّق، مقبول، مرفوض/مستخدم.
- حفظ القائمة والنتائج على الجهاز.
- فتح روابط مجموعات ومنشورات فيسبوك التي أدخلها المستخدم.

## حدود الوصول
قراءة التعليقات تلقائيًا من مجموعات فيسبوك تتطلب صلاحيات رسمية مناسبة من Meta؛ التطبيق يفحص فقط النص الذي ينسخه أو يشاركه المستخدم. التفعيل داخل نسك يتم يدويًا بعد مراجعة المستخدم للنتيجة.
