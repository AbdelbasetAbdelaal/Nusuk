# Nusuk Key Hunter

تطبيق أندرويد لتنظيم أكواد الدعوة التي تبدأ بـ NG- ومساعدتها في التجربة اليدوية داخل تطبيق نسك الرسمي.

## واجهة مدمجة لا تملأ الشاشة
- قائمة الأكواد مخفية افتراضيًا.
- زر «إظهار قائمة الأكواد» يعرض القائمة عند الحاجة، وزر «إخفاء قائمة الأكواد» يعيد إخفاءها.
- لا يعرض الكود الجاري تجربته على الشاشة؛ ينسخه إلى الحافظة ويعرض حالة تجهيز الكود فقط.
- النص المنسوخ من الحافظة لا يبقى معروضًا داخل مربع التعليقات بعد الفحص.
- حقول إدخال النص محدودة الارتفاع.

## مساعد نسك
1. اضغط «نسخ الكود التالي وفتح تطبيق نسك».
2. يختار التطبيق أول كود معلّق، ينسخه، ثم يفتح تطبيق نسك الرسمي.
3. أدخل الكود بنفسك في خانة الدعوة وأكمل العملية.
4. ارجع وسجّل النتيجة «تم قبوله» أو «مرفوض / مستخدم».
5. يحفظ التطبيق الحالة محليًا وينتقل إلى الكود التالي.

## إدارة الأكواد
- استخراج الأكواد التي تبدأ بـ NG- من النصوص المنسوخة أو المشتركة.
- منع التكرار.
- عرض القائمة عند الطلب فقط.
- تسجيل حالات الأكواد وحفظ البيانات محليًا.

التطبيق لا يقرأ تعليقات فيسبوك تلقائيًا ولا يرسل أو يفعّل رموز الدعوة داخل نسك دون تدخل المستخدم.
