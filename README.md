# Nusuk Key Hunter

تطبيق أندرويد لتنظيم أكواد الدعوة التي تجمعها بنفسك:
- لصق مجموعة أكواد وإزالة المكرر محليًا.
- نسخ الكود التالي لتدخله يدويًا في نسك.
- تسجيل نتيجة كل كود ومتابعة الأعداد.
- حفظ البيانات على الجهاز.

لا يتصل التطبيق بحساب نسك ولا يطلب كلمة مرور أو رمز تحقق، ولا ينفذ إدخالًا آليًا أو يتجاوز قيود الخدمة.

## بناء APK
GitHub Actions يبني APK عند كل دفع إلى main أو عند تشغيل Workflow يدويًا.
يمكن تنزيل الملف من Actions > Build Nusuk Key Hunter APK > Artifacts.
